* OSCDef
Simulate the OSCDef experience in SuperCollider.

Examples:

#+begin_src lisp :package lapork.oscdef
  (start-osc-listening)

  (oscdef-clear :test)

  ;; OSCDef
  (oscdef :test (&rest args)
    (format t "Got ~{~A~^, ~}~%" args))

  ;; OSCDef.add
  (oscdef+ :test (&rest args)
    (format t "Sum of args: ~A~%" (reduce #'* args)))
#+end_src
